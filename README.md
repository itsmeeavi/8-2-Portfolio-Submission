# 8-2-Portfolio-Submission

Project Overview

In this project I worked on a pirate intelligent agent that find its way through a maze to reach the treasure using deep Q learning and neural networks

The main goal of this project was to train the pirate to make better decisions by learning from its actions and rewards instead of just moving randomly around the maze

This project helped me understand more about reinforcement learning and how an intelligent agent can learn from experience

What work did I do on this project
For this project I was already given some starter code including the TreasureMaze and GameExperience classes along with the Jupyter Notebook

The TreasureMaze class was used to create the maze environment and manage the movements and rewards while the GameExperience class was used for storing the past experiences of the agent

Some of the other code was also provided like creating the neural network and showing the maze

My main work was completing the qtrain function where I had to write the training process for the pirate agent

I worked on how the agent choose between exploring random actions and using what it already learned to make better moves

I also worked with storing the experience, training the neural network, tracking the wins and losses and updating the model during training

At first understanding how all these parts works together was little confusing but after going through the code it started making more sense

During training the agent started to improve and it reached 100% win rate at epoch 308 and the completion check also returned True

Seeing the pirate actually learning to find the treasure helped me understand how reinforcement learning works in a practical way
